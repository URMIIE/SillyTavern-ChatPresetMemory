# 채팅별 설정 기억 (Chat Preset Memory)

채팅마다 **프롬프트(채팅 완성 프리셋·토글), 월드인포, 정규식** 상태를 기억했다가, 그 채팅을 다시 열면 그대로 맞춰 주는 확장이에요.

## 기능

- **채팅별 기억** — 채팅 파일에 저장해서 다른 브라우저·기기에서도 같아요. 무엇을 기억할지는 채팅마다 골라요.
  - **프롬프트** — 마지막 프리셋과, **프리셋마다** 켜 둔 토글.
  - **월드인포** — 전역 월드인포 선택, 그리고 이 채팅에 걸린 로어북(전역 · 채팅 · 캐릭터에 연결된 것)의 항목 켜짐/꺼짐.
  - **정규식** — 전역 · 프리셋 정규식 켜짐/꺼짐 (카드 정규식은 카드 파일이라 빼요).
- **채팅 안에서 프리셋을 바꾸면** — 이 채팅에서 그 프리셋으로 쓰던 토글이 바로 켜지고, 바꾼 상태를 다시 기억해요.
- **자동 적용** — 채팅을 열면 기억한 대로 맞춰져요. 다를 때만 바꿔요.
- **ⓘ 에서 보고 고치기** — 기억한 내용을 보면서 토글 · 월드인포 · 로어북 항목 · 정규식을 체크로 바로 켜고 꺼요(검색 가능). 바꾸면 지금 설정에 바로 적용되고 기억도 따라가요. 다른 프리셋에 기억해 둔 토글은 지울 수 있어요.
- **채팅마다 켜고 끄기** — 기억하고 싶지 않은 채팅은 스위치만 끄면 돼요.
- **캐릭터 기본값** — 새 채팅은 그 캐릭터의 마지막 설정으로 시작(끌 수 있어요).
- 브랜치는 원래 채팅의 기억을 물려받아요.
- **테마·모바일 대응**.

## 설치

실리태번 **확장 → 확장 설치**에 아래 주소를 붙여 넣어요.

```
https://github.com/URMIIE/SillyTavern-ChatPresetMemory
```

실리태번 1.19.0 이상, 채팅 완성 API에서 작동해요.

## 사용법

1. **AI 응답 설정 → 프롬프트**(프롬프트 관리자)를 열면 목록 위에 한 줄이 있어요.
2. 스위치 = 이 채팅 기억 켜기/끄기, 「프롬프트 · 월드인포 · 정규식」 = 이 채팅에서 기억할 것, ⓘ = 기억한 내용 보고 고치기.
3. 새 채팅에서 기본으로 기억할 것은 확장 설정(*채팅별 설정 기억*)에서 골라요.

## 알아 둘 것

- 맞출 프리셋에 없는 토글 · 없어진 로어북 항목 · 정규식은 건너뛰어요.
- 프리셋을 바꾸면 그 프리셋의 모델·샘플러 설정도 같이 바뀌어요(직접 고를 때와 같아요).
- 프리셋 이름이 바뀌었거나 지워졌으면 알림만 띄우고 아무것도 안 바꿔요.
- 월드인포 · 정규식은 실리태번 전체 설정이라, 이 채팅에서 맞추면 다른 채팅으로 가기 전까지 그대로예요. 다른 채팅도 기억을 켜 두면 열 때 그 채팅 상태로 돌아가요.
